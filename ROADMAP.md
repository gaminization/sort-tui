# Sort-TUI Roadmap

This roadmap outlines the past, present, and future trajectory of `sort-tui`. We welcome community contributions to help accelerate these goals.

---

## Phase 1: v0.1.0 (Current) - Alpha Foundations
- [x] Generator-based core architecture with zero external dependencies.
- [x] Interactive `curses` terminal renderer.
- [x] Massive catalog of 149 sorting algorithms.
- [x] Basic playback controls, time travel, and speed modulation.
- [x] Initial continuous integration and testing gates (85%+ coverage).

## Phase 2: v0.2.0 (Target) - Polish and Audio Integration
- [ ] Implement fully integrated cross-platform audio generation (Synth mapping).
- [ ] Support custom color palettes (e.g., Dracula, Nord) and high-contrast accessibility modes.
- [ ] Implement headless benchmarking CSV exports for detailed data science processing.
- [ ] Refine the interactive algorithm comparison view for split-screen competition.

## Phase 3: v1.0.0 (Stable) - Production Grade
- [ ] Full Windows native support (`windows-curses` integration or an alternate textual wrapper).
- [ ] WebAssembly / Browser frontend export capabilities via Textual or similar framework.
- [ ] Dynamic algorithm scripting API, allowing users to submit custom python sorts via CLI.
- [ ] Comprehensive educational documentation with built-in "step explanation" sidebars inside the TUI.
