# Sort-TUI Roadmap

## v0.1.0 (Current) - Alpha Foundations
- [x] Generator-based core architecture.
- [x] Interactive `curses` renderer.
- [x] Extensive catalog of 100+ sorting algorithms.
- [x] Basic playback controls and speed modulation.
- [x] Initial continuous integration and testing gates (85%+ coverage).

## v0.2.0 (Target) - Polish and Audio Integration
- [ ] Implement fully integrated cross-platform audio generation (Synth mapping).
- [ ] Support custom color palettes and high-contrast accessibility modes.
- [ ] Implement headless benchmarking CSV exports for detailed data science.
- [ ] Refine the interactive algorithm comparison view for split-screen competition.

## v1.0.0 (Stable) - Production Grade
- [ ] Full Windows native support (`windows-curses` or alternate renderer wrapper).
- [ ] WebAssembly / Textual frontend export capabilities.
- [ ] Algorithm scripting API allowing users to submit custom python sorts dynamically.
- [ ] Comprehensive educational documentation with built-in "step explanation" sidebars.
